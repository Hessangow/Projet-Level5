# LEVEL5 TABLEAU - collection de jeux vidéo (Express + EJS + cookie-session)

    npm install
    npm start
Ouvrir http://localhost:3000/jeux

| Action | Route                         |
|--------|-------------------------------|
| Read   | GET  /jeux                    |
| Create | POST /jeux/ajouter            |
| Update | GET /jeux/modif/:id puis POST /jeux/modifValide |
| Delete | GET  /jeux/supprimer/:id      |
